# MeowlWordle Streamer

Клиент MeowlWordle для стримеров Twitch на Windows.

1. Скачай EXE из [последнего бета-релиза](https://github.com/Artemiiiiyy/MeowlWordle-Streamer/releases) и открой его. Для клиента нужен Microsoft Edge WebView2 Runtime.
2. Войди в Twitch, выбери способ подключения бота и запусти игру.
3. Скопируй адрес из вкладки «Оформление» в браузерный источник OBS. Оставь клиент открытым на том же ПК.

Клиент проверяет релизы GitHub при запуске и во время работы. Если выходит новая версия, в приложении появляются кнопка «Обновить» и сообщение в разделе «Обновления». После подтверждения клиент скачивает и проверяет EXE, затем перезапускается. Пока клиент перезапускается, локальный оверлей OBS недоступен.

> **Пока сервис работает только тогда, когда компьютер владельца репозитория включён, подключён к интернету и на нём запущена «Стримерская».** Если компьютер выключен, спит или сервис остановлен, подключиться к игре не получится.
